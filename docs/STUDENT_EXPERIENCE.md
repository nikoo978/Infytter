# Experiencia del alumno — V1.09.3

Menú directo: Inicio, Entrenar, Ejercicios, Progreso y Perfil.

- Ejercicios permite búsqueda, filtros y consulta de técnica sin crear una rutina.
- En el editor, cada elección se puede desmarcar en el mismo lugar. “Ver ejercicio” consulta técnica y músculos sin cambiar la selección.
- Una rutina permite consultar sus ejercicios sin abrir una sesión de entrenamiento.
- Hombre/Mujer utiliza las láminas locales aportadas por el propietario. Las áreas táctiles y los recortes comparten coordenadas; brazos y piernas se recortan para mostrar el grupo seleccionado.
- El visor en pantalla completa permite zoom 1×–4×, pellizco y arrastre. Las imágenes normales no tienen zoom propio.
- Las series permiten marcar/desmarcar. Desmarcar cancela el descanso automático; la sincronización y las cargas siguen en el flujo existente.

Las mejoras no agregan tablas ni modifican membresías, roles o datos del gimnasio.
